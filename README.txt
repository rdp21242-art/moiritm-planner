# Мой ритм — личный планер для iPhone

## Содержимое
- `index.html` — интерфейс планера
- `manifest.webmanifest` и `sw.js` — установка как PWA и офлайн-кэш
- `icon-192.png`, `icon-512.png` — иконки

## Установка на iPhone
Для установки на домашний экран как приложение, Safari требует страницу, опубликованную по HTTPS.
Можно использовать любой статический хостинг, например GitHub Pages:
1. Создайте новый репозиторий GitHub.
2. Загрузите все файлы из архива в корень репозитория.
3. В Settings → Pages выберите публикацию из ветки `main`, папка `/root`.
4. Откройте получившийся HTTPS-адрес именно в Safari на iPhone.
5. Нажмите «Поделиться» → «На экран Домой» → «Добавить».

Регистрация в самом планере не нужна. Отметки хранятся в локальном хранилище браузера на устройстве. Экспортируйте резервную копию перед очисткой данных Safari. Если очистить данные сайта или использовать приватный режим, отметки могут пропасть.

`index.html` можно также открыть локально для предварительного просмотра, но установка с иконкой и офлайн-режим лучше работают после публикации по HTTPS.
